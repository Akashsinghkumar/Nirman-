# Nirman Consultants - Luxury Dark Theme Website

Official modern luxury website for **Nirman Consultants Kanpur** (Architects, Structural Engineers & Valuation Consultants, established 1991 by Ajay Gupta, IIT Roorkee).

## 🚀 Cloudflare Pages Deployment Guide

This project is built using vanilla HTML5, CSS3, JavaScript, and Swiper/Bootstrap utilities. It is optimized for zero-configuration instant deployment on **Cloudflare Pages**.

### Steps to Deploy:
1. Log in to your [Cloudflare Dashboard](https://dash.cloudflare.com/).
2. Navigate to **Workers & Pages** > **Create application** > **Pages** > **Connect to Git**.
3. Select the repository: `Akashsinghkumar/Nirman-`.
4. Configure Build settings:
   - **Framework preset**: `None`
   - **Build command**: *(leave completely empty)*
   - **Build output directory**: `/` *(or leave empty / default)*
   - **Root directory**: `/` *(default)*
5. Click **Save and Deploy**.
6. Cloudflare will automatically build and assign a production URL: `https://nirman.pages.dev` (or custom domain).

## 📁 Project Structure

- `index.html` - Homepage featuring luxury dark theme, hero slider, client logos, service overview, project highlights, and testimonials.
- `about.html` - About Nirman Consultants, history since 1991, leadership (Ajay Gupta), and credentials.
- `service.html` & `service-details.html` - Comprehensive architecture and structural engineering services.
- `project.html` & `project-details.html` - Landmark portfolio of 800+ completed projects.
- `clients.html` - Trusted corporate and institutional clients with high-resolution white logo cards.
- `faq.html` - Frequently asked questions with interactive accordion and consultation guidelines.
- `contact.html` - Kanpur office contact information, map, and consultation inquiry form.
- `style.css` - Global dark theme styling, typography, variables, responsive rules, and micro-interactions.
- `assets/` - Images, stylesheets, icons, fonts, and vendor libraries.
